# Разбор хоккейного матча

Статическое веб-приложение для разбора записей и трансляций VK Видео:

- метки по времени и игрокам;
- комментарии к эпизодам;
- рисование поверх остановленного видео;
- импорт и экспорт меток в JSON.

## Локальный запуск

Серверная часть и сборка не требуются. Запустите любой статический HTTP-сервер из корня проекта, например:

```bash
python3 -m http.server 8080 --directory dist
```

Затем откройте `http://localhost:8080`.

## Размещение

Скопируйте содержимое папки `dist` в корневую папку сайта на веб-сервере. Для корректной работы VK Видео сайт рекомендуется открывать по HTTPS.

Метки хранятся локально в браузере. Для переноса между устройствами используйте экспорт и загрузку JSON.
